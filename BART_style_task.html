Balloon Risk-Taking Task

In each round, press Pump to inflate the balloon and earn points.

You can press Collect at any time to save the points earned in that round.

If the balloon bursts before you collect, you lose the points from that round.

The balloon can burst at an unpredictable point, so choose when to stop.

This is a classroom BART-style task created for the project. It is not presented as a clinically validated assessment.
